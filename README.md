# KodxCamp

Browser-first, learn-by-doing programming platform.

## Stack
- **M**ongoDB + Mongoose
- **E**xpress + TypeScript
- **R**eact + Vite + TypeScript
- **N**ode.js

## Structure
- `client/` — React frontend
- `server/` — Express API
- `shared/` — Shared types

## Development
```bash
npm install
npm run dev
